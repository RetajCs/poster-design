# poster-design

Water Lilies — Poster Web Design

A small HTML/CSS art poster inspired by Claude Monet’s Water Lilies, created to explore the intersection of web development and visual design.

Overview

The project translates an art-inspired poster concept into a web page using typography, layout, imagery, spacing, and responsive CSS.

It is intentionally small: the goal was to practice creating a visually directed web experience while strengthening HTML and CSS fundamentals.

Features

* Art-inspired poster composition
* Custom typography using Google Fonts
* Responsive image sizing
* CSS-based layout and styling
* Combination of visual art and web presentation

Technologies

* HTML
* CSS
* Google Fonts

What I Learned

This project helped me think about a web page as a visual composition rather than only a collection of HTML elements — especially hierarchy, spacing, typography, and image presentation.
